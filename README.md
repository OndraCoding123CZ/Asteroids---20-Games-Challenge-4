# Asteroids (Completed ✅)

- A game where the player has to destroy the incoming asteroids, the player starts off with a score of 0 and each asteroid destroyed adds 100 to the score, the player as well starts with 3 lives and each time an asteroid collides with the player, the lives reduce by 1.
- Once the lives are at 0, a restart screen pops up.
- There are 2 versions of asteroids, the first one that spawns, and the second one that appears when the first one is destroyed. The way it works is when you destroy the first big asteroid, 2 small asteroids appear.

## Play Info

- You can play the game on itch.io, it is a web game that you play straight in the browser without having to download it.
